## 📋 RAILWAY BACKEND ENVIRONMENT VARIABLES
```
MONGO_URL=mongodb+srv://isitbusy:PASSWORD@isitbusy-cluster.xxxxx.mongodb.net/isitbusy
GOOGLE_PLACES_API_KEY=your_google_places_api_key_here
GEMINI_API_KEY=your_gemini_api_key_here
JWT_SECRET=your_super_secret_jwt_key_here_32_chars_minimum
CORS_ORIGINS=https://isitbusy.org,https://www.isitbusy.org
PORT=8000
ENVIRONMENT=production
```

## 📝 NOTES:
- MongoDB PASSWORD: MongoDB Atlas'ta oluşturduğunuz şifre
- GOOGLE_PLACES_API_KEY: Google Cloud Console'dan alacağınız key
- GEMINI_API_KEY: Google AI Studio'dan alacağınız key
- JWT_SECRET: En az 32 karakter, güçlü bir secret key
